# Cestovní deník — testování a zpětná vazba

Cestovní deník připravujeme pro macOS, iPhone a iPad. Tento repozitář slouží testerům k hlášení chyb, návrhům na zlepšení a sledování změn.

## Instalace přes TestFlight

Aplikaci i její aktualizace budete instalovat přes Apple TestFlight. Testovací pozvánku nebo odkaz doplníme po zpřístupnění ověřené testovací verze. V tomto repozitáři nejsou instalační soubory ani zdrojový kód aplikace.

**Stav: testovací distribuce se připravuje.** Zatím zde není potvrzená dostupná verze ani funkční pozvánka do TestFlightu.

## Zpětná vazba

- [Nahlásit chybu](https://github.com/Kuliss9/cestovni-denik/issues/new?template=chyba.yml)
- [Navrhnout vylepšení](https://github.com/Kuliss9/cestovni-denik/issues/new?template=navrh.yml)
- [Prohlédnout otevřená hlášení](https://github.com/Kuliss9/cestovni-denik/issues)

Nejprve ověřte, zda už stejné hlášení existuje. Pokud ano, přidejte své zkušenosti do něj. U chyby uveďte verzi a číslo sestavení, zařízení, verzi systému a postup, kterým lze problém zopakovat. Pro založení hlášení potřebujete účet GitHub a přístup k repozitáři.

Do hlášení a snímků nevkládejte API klíče, hesla, doklady, údaje z rezervací ani soukromá cestovní data. Použijte ukázková data nebo citlivé části zakryjte. Zpětnou vazbu lze poslat také přímo přes TestFlight; pro citlivé diagnostické podklady použijte tento soukromý kanál.

## Co se změnilo

[Releases](https://github.com/Kuliss9/cestovni-denik/releases) obsahují poznámky ke skutečně zpřístupněným testovacím sestavením: novinky, opravy, známá omezení a doporučené oblasti testování. Souhrnný přehled je v [CHANGELOG.md](CHANGELOG.md).

Verze a číslo sestavení v poznámkách musí odpovídat údajům v TestFlightu. Publikace poznámek na GitHubu sama nezpřístupňuje aplikaci testerům.
